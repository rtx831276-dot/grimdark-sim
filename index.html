MISSION 01 · BATAILLE SANS FIN

Deux forces fictives s’affrontent au carrefour avec pistolets, fusils, lames et combat à mains nues. Une créature hostile chasse les deux camps.

Renforts illimités : un combattant réapparaît 10 secondes après un décès ou une fuite. La créature réapparaît aussi après sa mort. La carte reste délimitée et la partie ne se termine pas automatiquement.

La bataille commence en pause.
Clic gauche / glisser : sélectionner · Clic droit : déplacer ou attaquer · Espace : lancer / pause

Les soldats signalent les ennemis et demandent du renfort aux alliés proches (messages texte, sans voix). Les deux camps sont jouables.

Mêlée · techniques et zones

L’IA alterne coups directs, enchaînements et balayages. Le coup touche uniquement si la zone de frappe rencontre un adversaire au moment de l’impact. Le balayage peut toucher deux ennemis.

Activez Hitboxes (K) : disques bleus = zones vulnérables, secteurs orange = attaques. Rouge = tick d’impact. Les coups de mêlée ne blessent pas les alliés.

Rôles des soldats
  • L / P · Lame / Pistolet : combattants équipés.
  • C · Chef : rallie ses camarades.
  • S · Combattant : polyvalent au contact.
  • F / G · Fusilier / Grenadier : fusil ; le grenadier peut lancer des grenades.
  • + · Médecin : soigne automatiquement un allié blessé proche quand il est disponible (3 charges).

Les grenades rebondissent sur les obstacles trop hauts et explosent après leur mèche (attention aux alliés, et au lanceur, dans la zone). Sélectionnez un soldat pour voir ses capacités.

Aide · commandes
  • Clic gauche — sélectionner une unité ; clic glissé — sélectionner un groupe ; Maj + clic — ajouter / retirer.
  • Clic droit — ordre de déplacement, ou d'attaque sur un ennemi.
  • Mode FPS — sélectionnez un soldat (ou laissez le jeu choisir un fusilier), puis cliquez Mode FPS. Souris : viser ; ZQSD/WASD : bouger ; clic gauche : tirer ou frapper ; clic droit maintenu : zoom avec une arme à feu ; R : recharger ; Échap libère la souris, « Quitter FPS » revient à la vue tactique.
  • X / V — pivoter la caméra (vue 3D).
  • Molette — zoom ; clic central ou ZQSD/WASD — déplacer la caméra.
  • F / H / R / T — assaut, tenir, repli, ralliement.
  • C / L / P / K — couverture, lignes de vue, chemins, hitboxes.
  • Espace — pause ; 1 / 2 / 3 — vitesse ×1, ×2, ×4.

Les deux camps sont pilotables : c'est un bac à sable. Sans ordre, chaque unité applique sa doctrine : chercher un couvert, arroser l'ennemi, avancer sur les objectifs, se replier quand le moral casse.
